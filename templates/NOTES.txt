{{- if .Values.seafile.webdav.enabled }}

  WARNING: the chart opened the port and route for WebDAV, but it
  can't enable the service itself — Seafile only reads this flag from
  seafdav.conf, and upstream never added an environment variable for
  it. Until the flag is set, {{ .Values.ingress.webdav.path }} returns 502. Run this once:

    kubectl exec -n {{ .Release.Namespace }} {{ include "seafile.fullname" . }}-0 -- \
      sed -i 's/^enabled = false/enabled = true/' /shared/seafile/conf/seafdav.conf
    kubectl rollout restart sts/{{ include "seafile.fullname" . }} -n {{ .Release.Namespace }}

  The edit lives in the PVC and survives restarts.
{{- end }}

  The first startup initializes the databases and takes a few minutes.
  Progress:

    kubectl logs -n {{ .Release.Namespace }} -f {{ include "seafile.fullname" . }}-0

  Check that it's working:

    helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
